Open tools for closed systems.

Fieldmouse Works builds open-source software for ecosystems that are expensive, restrictive, difficult to leave, or designed around permanent vendor dependence. The goal is practical: you should be able to run the software, understand it, move your data, and keep operating on your own terms.

Current projects

Conary

Language
Rust
License
MIT
Status
early preview

A cross-distro Linux package manager that installs RPM, DEB, and Arch packages across Fedora, Ubuntu, and Arch while preserving each format's lifecycle semantics.

Conary runs those formats through one atomic, content-addressed transaction model with history, rollback, and immutable system generations. The maintainer-operated Remi service provides package conversion and metadata.

Early preview: use a VM or a non-critical host.

Self-hosted training-record software for emergency communications, designed around versioned programs, immutable finalized records, acknowledgments, lawful disposition, recovery, and portable exports.

Consolebook is an open alternative to closed public-safety training and employee-record systems, with agency-owned data and self-hosting as first-class requirements.

Pre-alpha: design and buildable scaffold.

About the name

Fieldmouse Works is named for the small creature willing to take on something much larger than itself. That is a useful model for the work here: find the closed system, understand what it actually does, and build the open door.

Built by Peter Permenter, a systems and backend engineer focused on explicit state, reproducible behavior, recovery, portability, and software that stays operable without a permanent vendor relationship.
